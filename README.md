# קרן הקצבה

אפליקציית SPA לניהול קרן שממנה משולמת קצבה חודשית, עם דגש על משמעת החלטות
ולא על ניתוח שוק. עברית, RTL, PWA, ללא build.

## הפעלה

```bash
python3 -m http.server 8000
```
ואז `http://localhost:8000`.

## אחסון

הנתונים נשמרים ב-Google Drive דרך Apps Script Web App שרץ בחשבון שלך —
**בלי OAuth ובלי מסך התחברות**. פריסה חד-פעמית: ראה
[`apps-script/README.md`](apps-script/README.md), ואז הזן את הכתובת והטוקן
במסך **אחסון**.

עד שהאחסון מוגדר האפליקציה עובדת מקומית (IndexedDB) ומסמנת זאת.

## נקודת פתיחה

במקום להזין את התיק ידנית אפשר לטעון קובץ JSON אחד: **אחסון › נקודת פתיחה**.
ההנחיה להפקת הקובץ — כולל הסכמה המלאה ודוגמה — נמצאת ב-
[`docs/הנחיה-ליועץ.md`](docs/הנחיה-ליועץ.md), ומיועדת להדבקה בפרויקט של
היועץ. הקובץ נבדק ומוצג לאישור לפני שהוא נוגע במצב.

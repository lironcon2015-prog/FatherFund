# פריסת שכבת ה-Drive

פעולה חד-פעמית. אחריה האפליקציה מדברת עם Drive בלי שום מסך התחברות, בכל
מכשיר ובכל דפדפן.

## 1. יצירת הסקריפט

1. גש ל-<https://script.google.com> ולחץ **פרויקט חדש**.
2. מחק את התוכן של `Code.gs` והדבק במקומו את `apps-script/Code.gs` מהריפו.
3. בשורה `var TOKEN = '...'` — החלף במחרוזת אקראית ארוכה. למשל, הרץ בטרמינל:
   ```
   openssl rand -hex 24
   ```
4. שמור.

## 2. פריסה

**פריסה › פריסה חדשה › סוג: אפליקציית אינטרנט**

| שדה | ערך |
|---|---|
| הפעל בתור | **אני** (`me`) |
| למי יש גישה | **לכל מי שיש לו הקישור** (`Anyone`) |

בפעם הראשונה גוגל תבקש הרשאות ותציג אזהרת "אפליקציה לא מאומתת" — זה צפוי,
זה הסקריפט שלך. לחץ **מתקדם › עבור אל …**.

העתק את כתובת ה-Web App. היא נראית כך:
`https://script.google.com/macros/s/AKfycb.../exec`

## 3. חיבור האפליקציה

פתח את האפליקציה › **הגדרות** › **אחסון**, והדבק את שני הערכים: הכתובת
והטוקן. הם נשמרים מקומית בדפדפן ונבדקים מיד בלחיצה על "בדוק חיבור".

לחלופין אפשר לקבע אותם בקוד, בראש `drive.js`:
```js
const FUND_DRIVE_URL   = 'https://script.google.com/macros/s/.../exec'
const FUND_DRIVE_TOKEN = '...'
```

## 4. מה נוצר בדרייב

```
/קרן-הקצבה/
  fund-state.json       ← מצב מלא. מקור האמת.
  /snapshots/           ← append-only. לעולם לא נדרס.
  /reports/             ← דוחות שהופקו
  מצב-הקרן.md           ← Report D
  חבילת-חירום.html      ← Report E
```

## מה שחשוב לדעת

- **מי שמחזיק את הכתובת ואת הטוקן — קורא וכותב.** אין כאן זהות משתמש. זו
  ההחלטה שהתקבלה במודע כדי להימנע ממסך התחברות, והיא סבירה לנתונים האלה
  (אין פרטי חשבון, אין יכולת להזיז כסף). אל תפרסם את הכתובת ואל תדביק אותה
  בצ'אט קבוצתי.
- **החלפת טוקן** = עריכת `TOKEN` בסקריפט, **פריסה › ניהול פריסות › עריכה ›
  גרסה חדשה**, ועדכון האפליקציה. הכתובת לא משתנה.
- **גישת האחים** לתיקיית `/reports/` נעשית בשיתוף Drive רגיל, בהרשאת צפייה,
  על תיקיית `reports` בלבד — לא על `/קרן-הקצבה/` כולה.
- אם תמחק את הפריסה, הנתונים נשארים. הם קבצים רגילים בדרייב שלך.
